# めろ～ん王国 騎空団ポータル＆古戦場周回効率計算ツール

グランブルーファンタジー（グラブル）騎空団「めろ～ん王国」専用の閲覧用ポータルサイトおよび古戦場周回効率計算機です。

---

## 🌟 主な機能

1. **騎空団員専用ポータル (`gbf-crew-portal`)**:
   - **合言葉認証ゲート**: 団員30名専用のパスワード認証機能（初期パスワード: `[REMOVED]`）。
   - **古戦場・イベント日程**: 予選・集計・インターバル・本戦各日・SPバトルの詳細タイムライン。
   - **団規約等**: 古戦場ノルマ（4戦目250HELL20体/15億）、ドレッドバラージュノルマ（150万）、禁止事項、マルチ救援ルール。
   - **現在の団員募集内容**: ワンクリック全文コピー機能付きの最新募集要項。
   - **ツール連携**: 古戦場周回効率計算機へのスムーズなアクセス。
   - **更新履歴**: 団内ポータルの更新ログ。

2. **古戦場 周回効率計算機 (`時速ツール` / `gbf-unf-calculator`)**:
   - 90HELL〜250HELL難易度別対応。
   - 討伐秒数・硬直秒数をもとに、1時間あたりの周回数・獲得貢献度時速・消費肉数を自動計算。
   - 目標貢献度（10億・20億等）からの必要周回数・所要時間・必要肉数の逆算シミュレーション。

```bash
cd gbf-crew-portal
npm install
npm run dev
```
